# 2. Two Bears, Two Honest Answers

Sugar Bear and Little Bear looked at the same pale star.

“I see it,” said Sugar Bear.

“I do not,” said Little Bear.

Neither bear was lying.

Sugar Bear had a telescope. Little Bear had sleepy eyes.

Each bear had a different **observer rule**: a smallest difference the bear could notice.

We call that rule a **resolution**.

If a change is smaller than an observer's resolution, it looks unchanged. If it is larger, the observer notices it.

So “different” is sometimes an unfinished sentence.

The full question is:

> Different to which observer, using which resolution?

We can write an observer as \(O\) and the smallest change it notices as \(\epsilon_O\). The symbols are only name tags. The story came first.

## Tiny lesson

Two observers can give different honest answers because they can notice different things.

## Honey check

Can a dog hear something a person cannot? Did the sound exist for one observer but not the other?
